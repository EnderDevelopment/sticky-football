# StickyFootball: Roblox Universe Football Game

StickyFootball is a Roblox script designed for Universe Football games. It features an auto-sticky mechanism that pulls the player to the nearest person, a movable GUI for adjusting pull power and stickiness, and a feature to teleport the nearest ball to the player. This script is perfect for enhancing the gameplay experience in Roblox Universe Football games.

## Install

1. Create a new Roblox game or open an existing one.
2. Navigate to the `ServerScriptService` in the Explorer.
3. Create a new `ModuleScript` and name it `AutoStickyModule`.
4. Copy the contents of `AutoStickyModule.lua` into the `AutoStickyModule` ModuleScript.
5. Create another `ModuleScript` and name it `BallTeleportModule`.
6. Copy the contents of `BallTeleportModule.lua` into the `BallTeleportModule` ModuleScript.
7. Navigate to the `StarterPlayerScripts` in the Explorer.
8. Create a new `LocalScript` and name it `PullPowerGUI`.
9. Copy the contents of `PullPowerGUI.lua` into the `PullPowerGUI` LocalScript.
10. Create another `LocalScript` and name it `StickinessGUI`.
11. Copy the contents of `StickinessGUI.lua` into the `StickinessGUI` LocalScript.
12. Tag all ball objects with the "Ball" tag in the CollectionService.

## Use

1. Launch the Roblox game.
2. The auto-sticky feature will automatically pull the player to the nearest person.
3. Use the movable GUI to adjust the pull power and stickiness by entering values in the text boxes and pressing Enter.
4. To teleport the nearest ball to the player, use the `BallTeleportModule` function.
